# Scenario Analysis with Multivariate Bayesian Machine Learning Models
This repository is reserved for collecting data, codes and replication files for the paper "Scenario Analysis with Multivariate Bayesian Machine Learning Models" by Michael Pfarrhofer and Anna Stelzer (working paper available at [https://arxiv.org/abs/2402.10574](https://arxiv.org/abs/2502.08440)).
